## Описание

**Input VPN** — бесплатный VPN-клиент с открытым исходным кодом для Windows 10/11. Работает на современном ядре **sing-box** и поддерживает самые популярные протоколы из коробки. Никаких лишних программ — просто добавь конфигурацию и подключись.

## Возможности

- **Протоколы** — VLESS, VMess, Trojan, Shadowsocks (включая REALITY).
- **Системный VPN (TUN)** — туннелирование всего трафика; UAC запрашивается **один раз** при первом запуске, дальше подключается без запроса.
- **Режим SOCKS5** — локальный прокси на `127.0.0.1:11080`, права администратора не нужны.
- **Подписки** — добавь одну ссылку или целую подписку (Base64 / plain text).
- **Управление серверами** — пинг, выбор, переименование, редактирование, удаление.
- **Статистика в реальном времени** — скорость загрузки/отдачи, общий трафик и пинг прямо на главном экране.
- **Ватчдог** — автоматическое переподключение при аварийном выходе VPN-ядра.
- **Журнал событий** — история подключений и ошибок с метками времени.
- **Раздельное туннелирование** — выбери приложения, которые обходят VPN.
- **DNS-пресеты** — Cloudflare, Google, Quad9 или пользовательские DNS.
- **Режим трея** — сворачивание в системный трей вместо закрытия.
- **Темы и язык** — тёмная/светлая тема, интерфейс на русском и английском.
- **Проверка обновлений** — встроенная проверка новых релизов через GitHub.

## Скачать и установить

1. Перейди в раздел **[Releases](https://github.com/elev1e1nSure/input-vpn-app/releases/latest)**.
2. Скачай `InputVPN-Setup.exe`.
3. Запусти установщик и следуй инструкциям.
4. Открой **Input VPN** из меню Пуск или с рабочего стола.

## Быстрый старт

1. **Добавь сервер**
   - Открой вкладку **Серверы**.
   - Вставь одиночную ссылку (`vless://...`, `vmess://...`, `ss://...`, `trojan://...`) или URL подписки.
2. **Выбери и подключись**
   - Нажми на нужный сервер в списке.
   - Нажми большую **кнопку питания** на главном экране.
   - При первом запуске приложение регистрирует фоновую задачу — появится **один запрос UAC**. Дальше подключения бесшумные.
3. **Готово!**
   - На главном экране появятся публичный IP, пинг и скорость трафика.

## Настройки

| Настройка | Что делает |
|-----------|-----------|
| **SOCKS Debug Mode** | Запускает sing-box как локальный SOCKS5-прокси вместо системного TUN. UAC не требуется. |
| **Сворачивать в трей** | Закрытие окна прячет приложение в системный трей вместо выхода. |
| **Раздельное туннелирование** | Выбери приложения, которые будут обходить VPN. |
| **DNS** | Выбери пресет (Cloudflare, Google, Quad9) или введи свои DNS-серверы. |
| **Автообновление подписки** | Периодически обновляет подписку в фоне. |
| **Тёмная тема** | Переключение между светлой и тёмной темой. |
| **Язык** | Переключение между English и Русский. |

## Решение проблем

| Проблема | Решение |
|----------|---------|
| "VPN engine failed to start" | Убедись, что `sing-box.exe` есть рядом с приложением (входит в состав установщика). |
| Запрос UAC при каждом подключении | Должно быть только при первом запуске. Если повторяется — удали `%APPDATA%\inputvpn\Input VPN\` для сброса. |
| Нет трафика / 0 KB/s | Сервер может быть недоступен или конфиг содержит неверный UUID/SNI. Проверь в другом клиенте. |
| Приложение не запускается / падает | Удали `%APPDATA%\inputvpn\Input VPN\singbox\` для сброса повреждённого конфига и логов. |
| Пинг показывает "—" | Сервер недоступен или удалённый хост блокирует ICMP. |

## Системные требования

- Windows 10 версии 1809+ или Windows 11
- 64-битная (x64) архитектура
- Права администратора (один раз, при первом запуске)

## Для разработчиков

### Требования

- Flutter stable, включён Windows desktop
- Visual Studio 2022 — обязателен воркload **"Desktop development with C++"**
- `sing-box.exe` (v1.13.x, Win64) + `wintun.dll` → положить в `windows/runner/resources/`
- Inno Setup 6 — только для сборки установщика

### Сборка

```powershell
flutter pub get
flutter build windows --release
# Portable: build\windows\x64\runner\Release\
```

### Установщик

```powershell
iscc installer.iss
# Результат: Output\InputVPN-Setup.exe
```

Архитектура, соглашения и правила кода — в [`CLAUDE.md`](./CLAUDE.md).
